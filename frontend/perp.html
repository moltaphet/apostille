The integration is this

ApostilleFees fails open: if the registry can't be read, the base fee applies, so trading never depends on Apostille being up. The protocol also caps the discount it grants. 

using ApostilleFees for IApostille;

function trade(int256 sizeDelta) external {
  uint256 notional = abs(sizeDelta);
  (uint256 fee, , ) = apostille.feeOn(
    msg.sender, notional, baseFeePips, maxDiscountBps
  );
  margin[msg.sender] -= fee;
  // ...
}

Fees in this demo: 0.05% base taker fee, discount capped at 50%.
