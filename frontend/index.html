How it works

01

Read at the source

Primus zkTLS attests the response of Binance's own vip-fee-summary endpoint: VIP level, 30-day spot and futures volume.

02

Reveal only what matters

Your Binance user id is SHA256-hashed inside the proof. The hash is a nullifier: one exchange account backs one wallet at a time.

03

Verified on-chain

The contract checks the attestor signature, endpoint, JSON paths, freshness and recipient before it records anything.

Integrate in one call

Perp DEXs, launchpads and lending markets can read a wallet's tier without trusting a screenshot or a spreadsheet.

interface IApostille {
    function tierOf(address wallet)
        external view returns (bool active, uint8 tier, uint16 discountBps);
}

(bool active, , uint16 discountBps) = IApostille(APOSTILLE).tierOf(trader);
uint256 fee = active ? baseFee * (10_000 - discountBps) / 10_000 : baseFee;
